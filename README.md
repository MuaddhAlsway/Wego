## 💡 Overview Report
This project is a static HTML and CSS replica of the Wego platform. It focuses on replicating the layout and design of Wego's homepage and key elements, without responsive design or JavaScript functionality.

## 🔶 Highlight Features
- **Homepage** with a logo and language selection.
- **Authentication Buttons**: 'Login' and 'Get Started'.
- **Navigation Icons**: Flight, Hotel, and Business (non-interactive).
- **Search Functionality**:
  - One-way, Round-up, and Round-trip options.
  - Input fields for 'From' and 'To' locations.
  - Debug, Return, and Filter buttons.
  - Search button.
- **Image Section**: Four images with corresponding titles.

## 📂 Project Structure  
```
Wego-Clone/
├── Wego.html          # Main HTML file
├── Wego.css           # CSS stylesheet
└── image/             # Directory for images
```

## How to Use
1. Clone the repository:
   ```sh
   git clone https://github.com/MuaddhAlsway/Wego..
   ```
2. Navigate to the project directory:
   ```sh
   cd Wego
   ```
3. Open `index.html` in a browser to view the project.
